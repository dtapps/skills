# 腾讯新闻（tencent-news）

## 描述

7×24 新闻资讯搜索工具，聚焦中国国内信息和国际热点。支持新闻搜索，包括热点新闻、早报晚报、实时资讯、领域新闻和天气信息查询。当用户需要搜索新闻、新闻热榜、新闻早晚报、订阅新闻推送、获取相关新闻资讯和查询天气信息时使用

## 使用方法

```bash
dtskills tencent-news [command] [flags]
```

## 命令
### evening

获取新闻晚报

**用法：**
```bash
dtskills tencent-news evening
```
**参数：**

| 参数 | 简写 | 描述 | 必填 | 默认值 |
|------|------|------|------|--------|
| `--verbose` | `-v` | 输出完整结果 | 否 | false |

**输出字段：**

| 字段名 | 描述 |
|--------|------|
| `abstract` | 摘要 |
| `source` | 来源 |
| `timestamp` | 时间戳 |
| `title` | 标题 |
| `url` | 链接 |
